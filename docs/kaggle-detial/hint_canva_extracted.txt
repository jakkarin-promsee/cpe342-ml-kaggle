How Your Kaggle Score Converts to a Grade

Above Baseline (guarantee grade at α%)

Grade% = α + [(100% − α) × Φ(t)]

T-Score  t = (Your Score − μ) / σ
μ = mean of scores above baseline   σ = std. dev. of scores above baseline
Φ(t) = Standard Normal CDF (Z-table)

Baseline — designed to be achievable by everyone

Below Baseline

Grade% = α × (Your Score / Baseline)

Example grading shown uses α = 60%.

==================== PAGE 15 ====================

TASK 1

Anti-Cheat Pre-Filter

Your Task

Build a binary classifier to automatically pre-filter reports and prioritize high-confidence suspicious accounts for manual review.

ML Task

Binary Classification

Metric: F2

F2 = 5 · (P·R) / (4P + R)

Target: is_cheater (0=Legitimate, 1=Cheater)

Features Example

kill_death_ratio (float): kills-to-deaths ratio

headshot_percentage (float): % kills that are headshots

win_rate (float): overall win rate %

accuracy_score (float): shot accuracy %

reaction_time_ms (float): avg. reaction time (ms)

33 features total (32 predictive + target)

💡  Hints & Best Practices

Handle missing values — impute or drop carefully

Handle class imbalance: resampling, class weights, SMOTE

Feature engineering — build interaction features

Use cross-validation for reliable performance

Try decision-threshold tuning

Ensemble models for robustness

TASK 2

Player Segment Classification

Your Task

Classify each player into one of four behavioral segments to enable targeted marketing and personalized experiences.

ML Task

Multi-class Classification

Metric: F1

F1 = 2 · (P·R) / (P + R)

Target: segment (0=Casual, 1=Grinder, 2=Social, 3=Whale)

Features Example

play_frequency (float): avg. days/week played

avg_session_duration (float): avg. session length (min)

total_spending_thb (float): lifetime spending

avg_monthly_spending (float): average monthly spend

friend_count (float): number of in-game friends

45 features total (44 predictive + target)

💡  Hints & Best Practices

Leverage Task 1 tips — missing values & imbalance

Use Stratified K-Fold to preserve class distribution

Try XGBoost, LightGBM, or CatBoost

Stack these models together for extra robustness

Engineer interaction & ratio features

TASK 3

Player Monthly Spending Prediction

Your Task

Predict how much (in THB) each player will spend on in-game currency and items in the next 30 days.

ML Task

Regression

Metric: Normalized MAE

NMAE = 1 / (1 + Σ|y−ŷ| / Σy)

Target: spending_30d (continuous, THB)

Features Example

friend_count (float): number of in-game friends

event_participation_rate (float): % limited-time events joined

daily_login_streak (float): current login streak

avg_session_length (float): avg. session duration (min)

historical_spending (float): past spending

33 features total (32 predictive + target)

💡  Hints & Best Practices

Zero-inflated data — try a two-stage model: 
         (1) will spend? (2) how much?

Feature engineering & log transformation of target

Try XGBoost / LightGBM / CatBoost Regressors

Ensemble / stacking for extra accuracy

Watch for common mistakes in target scaling

==================== PAGE 21 ====================

TASK 4

Game Title Detection

Your Task

Build an image classifier that identifies which Karena game is being played from a single screenshot.

ML Task

Image Classification (Multi-Class)

Metric: F1 (Macro)

F1 = 2 · (P·R) / (P + R)

Target: game_title (5 classes)

Features Example

Gameplay screenshots (144p, centered crop to 230x120)

Sources: live streams, submissions, forums, tickets

Variety: different maps, phases, weather, UI states

5 classes: 7-11K, fiveN, freefried, pube, roblock

Pre-trained models allowed for this task

💡  Hints & Best Practices

Review image classification basics & data augmentation

Watch for class imbalance in images

Try VGG16/VGG19, Vision Transformer (ViT), Swin Transformer

Use cross-validation for CNNs; ensemble methods help

You may need a GPU — Colab/Kaggle offer free T4 GPUs

Kaggle: ~30 GPU hrs/week; Colab: dynamic, no fixed limit

==================== PAGE 23 ====================

TASK 5

Account Security Monitoring

Your Task

Build an unsupervised anomaly detection model to flag accounts with unusual behavior, using techniques like Isolation Forest or Autoencoders — without relying on labeled training data.

ML Task

Anomaly Detection (Unsupervised)

Metric: F3

F3 = 10 · (P·R) / (9P + R)

Target: is_anomaly (0=Normal, 1=Anomalous)

Features Example

login_count_1/2/3/4 (float): logins per time period

login_lat/lon_1/2/3/4 (float): login coordinates

location_changes_1/2/3/4 (float): significant location changes

device_count_1/2/3/4 (float): unique devices used

33 features total (32 predictive + target)

Note: no labeled training set provided — test.csv only

💡  Hints & Best Practices

Try Isolation Forest, One-Class SVM, or Auto-Encoder

Even unsupervised models can be ensembled

Read up on soft vs. hard voting techniques

Tune contamination / threshold carefully
