# Task 3 — Monthly Spending Prediction

The instructor's 12 November dataset update did not change Task 3. The existing `data/raw/train.csv`, `data/raw/test.csv`, and `data/raw/datacard.txt` remain current. The EDA notebooks in `eda/` save `eda_original_v1` and `eda_combined_v1` with their JSON cards and Train/Test Parquet splits.

`models/build_model.ipynb` contains the original model comparisons and five development-fold analyses. `models/build_model_v2.ipynb` reads `eda_combined_v1` directly from its card, uses the same development/holdout split, and tests a fixed CatBoost/LightGBM blend, a zero-aware classifier plus positive-amount model, and a fixed mixture of those candidates. `models/build_model_v3.ipynb` compares three from-scratch PyTorch tabular networks on the same folds. `eda/analyze_top_model_errors_1.ipynb` audits the selected mixture's OOF errors, and `eda/build_eda_2.ipynb` saves one targeted `eda_spend_persistence_v2` dataset. `models/build_model_v4.ipynb` tests new occurrence and amount features separately. `models/build_model_v5.ipynb` tests a log-transformed positive amount target; `models/build_model_v6.ipynb` refits its selected procedure on all labeled Train rows; `models/build_model_v7.ipynb` checks log-RMSE and a fixed log-MAE/log-RMSE amount blend. Each fitted candidate has a distinct saved model and evaluation card. Fold predictions are cached in `models/results/` for review and guarded reruns.

The new local candidate is `t3_log_positive_amount_full_v6`. Its selected v5 procedure scored **2,814.97 THB mean development-fold MAE** versus **2,895.92 THB** for the previous mixture, winning all five paired folds; the reused holdout improved from **2,845.10 to 2,780.94 THB**. Log-RMSE alone loses on all five folds; its fixed half blend with log-MAE improves mean MAE by only **3.81 THB**, too little to replace v6. The v6 evaluation card is the earlier procedure estimate, not a fresh score for the full-data fit. `src/submission/assemble_task3_log_v13.ipynb` creates an unsubmitted combined candidate that changes only Task 3 from the scored v9 baseline. The instruction slide states an NMAE formula, but the Kaggle implementation has not been independently confirmed; these are MAE scores, not official NMAE.
