# Task 2 — Player Segment Classification

The refreshed competition CSVs are in `data/raw/train.csv` and `data/raw/test.csv`. The files ending in `-outdate-12-11-2026.csv` and all `v1` EDA and model artifacts remain available for tracing the previous dataset.

Run `eda/build_eda_original_v2.ipynb` and `eda/build_eda_1_v2.ipynb` for the refreshed data. They save `eda_original_v2` and `eda_combined_v2`. `models/build_model_v2.ipynb` reads those cards and saves distinct `v2` model artifacts. The notebook retains the original feature and model logic while changing input paths and artifact names.

`models/build_model_v3.ipynb` reuses `eda_original_v2` and the saved CatBoost baseline. It checks class-level errors, fits probability biases on five development folds, and evaluates one saved decision-rule wrapper on the reused holdout. Holdout macro F1 increases from **0.75041** to **0.75222**, but the leave-one-fold-out gain is only **0.00020** on average, so it has not replaced the scored Task 2 submission. See [`docs/research-note-task2.md`](../../docs/research-note-task2.md) for the comparison and limitations.

`models/build_model_v4.ipynb` checks the undercalled Social and Whale classes with fixed CatBoost training weights `[1, 1, 1.25, 1.25]`. It reuses the same five development folds and trains a distinct saved model. Mean paired CV macro F1 is **0.75310** versus **0.75256** for the baseline (3/5 fold wins); reused holdout is **0.75285** versus **0.75041**. The modest CV gain is insufficient to change the conservative submission choice. The notebook includes OOF confusion and per-class precision/recall/F1.

`eda/analyze_top_model_errors_1.ipynb` audits the cached OOF predictions at row and group level, including confidence, confusion directions, missingness, tier combinations, and the rows rescued or broken by weighting. `eda/build_eda_tier_cross_v2.ipynb` saves exactly one new dataset with `loyalty_engagement_cross`; `models/build_model_v5.ipynb` tests that single interaction on the same five folds. CV macro F1 changes only **0.75256→0.75265** (2/5 wins), while the reused holdout falls **0.75041→0.74958**. See the research note for interpretation and the unresolved tier timing question.

`models/build_model_v6.ipynb` runs a bounded CatBoost parameter search on a stratified 40,000-row development subset, then checks three finalists against baseline on the same five full-development folds. The best tuned configuration scores **0.754095** macro F1 versus **0.752564** baseline; the three-tier ablation scores **0.587355**. `models/build_model_v7.ipynb` checks the previously tested Social/Whale class weights on that tuned configuration: **0.754156** across five folds, only **+0.000061** over unweighted v6. Both notebooks save separate development-fitted models and evaluate once on the reused 20% holdout. `models/build_model_v8.ipynb` refits the tuned weighted candidate on all labeled Train rows and records the earlier CV score as a **procedure estimate**, not as a score measured on the full fit.

The current datacard calls `vip_tier` a current level, `engagement_level` a classification, and `loyalty_tier` spending-based. No supplied file specifies when these were calculated relative to `segment`. Train/Test schema availability and the large no-tier ablation gap do not resolve temporal provenance. See the research note for the audit and model-selection limits.

The full-data candidate has a local, **unscored** combined CSV at `../submission/kaggle_t12345_t2_tuned_v12.csv`, built by `../submission/assemble_task2_tuned_v12.ipynb`. It keeps Tasks 1, 3, 4, and 5 identical to the scored v9 submission and maps Task 2 Test predictions by verified row order to the sample's `ANS` IDs. Its JSON card records the base hash, model lineage, and changed-row count.

`models/build_model_v9.ipynb` checks the slide's ensemble hint on five paired development folds, using saved CatBoost OOF probabilities and fold-fitted LightGBM/XGBoost pipelines. The best fixed soft ensemble scores **0.752148** macro F1 versus **0.754156** for the tuned weighted CatBoost and loses on all five folds. No ensemble replaces the full-data v8 candidate. A learned stack was not fitted because the simple ensemble showed no useful headroom; see the research note for the exact comparisons.
