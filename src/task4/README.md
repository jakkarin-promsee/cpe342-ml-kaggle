# Task 4 — Game Title Detection

The current `data/raw/test.csv` has `id,file_name,label` and uses `ANS...` IDs in a new order. `train.csv` has the same schema. The image files and train labels match the previous dataset; the old manifests and `v1` artifacts remain available.

Run `eda/build_eda_original_v2.ipynb` and `eda/build_eda_1_v2.ipynb` to create the refreshed EDA cards. They map `file_name` to the existing image features, verify SHA-256 for every current image, and preserve the new manifest IDs and order. `models/build_model_v2.ipynb` copies all 28 fitted candidates into new `r2` model artifacts linked to the `v2` EDA cards and checks each validation score. It does not retrain, because the train images and labels are unchanged.

`models/build_model_v2.ipynb` now continues from those copied baselines into direct-image training. It compares a frozen pretrained ResNet18, plain fine-tuning, geometry augmentation, geometry plus blur/noise, and ±180° rotation on the original image-hash grouped fold. A second grouped fold compares the leading procedures; a third checks the selected geometry procedure. The selected geometry procedure averages **0.95447 macro F1** across the three grouped folds. The full-data model `t4_resnet18_geometry_full_v2` uses all labeled Train images and a fixed seven-epoch fit. Its `macro_F1_grouped_cv3` evaluation is the grouped-fold procedure estimate, not a validation score on the full-data checkpoint.

The notebook uses PyTorch and torchvision in addition to the repository's base requirements. On the tested Windows RTX 3050 Ti environment, run `uv pip install --python .venv\Scripts\python.exe -r src/task4/models/requirements-image.txt`. The optional file pins `torch==2.11.0+cu128` and `torchvision==0.26.0+cu128` from the PyTorch CUDA 12.8 index. The checkpoint contains the complete network weights and inference preprocessing metadata. `image_training.py` loads it without downloading weights.

Run the notebook from top to bottom; existing model names are guarded before fitting. It saves a pipe-separated per-task prediction file and card at `submission/t4_resnet18_geometry_full_v2.csv` and `.json`. The file has `id|task4` columns and current `ANS` IDs. Use this selected model explicitly when assembling a new five-task Kaggle submission; the older `r1`/`r2` LightGBM entries remain in the evaluation index.
